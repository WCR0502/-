# 参赛材料仓库

本仓库用于存放参赛所需的全部材料，请按以下目录结构归类上传。

## 目录结构

```
├── 01-项目白皮书/
│   ├── 01-项目概述/            # 项目背景、应用范围、核心优势等
│   ├── 02-解决方案/            # 架构设计、方案功能、技术内容等
│   ├── 03-应用成效/            # 应用情况总述、具体应用案例介绍等
│   ├── 04-商业模式/            # 推广模式、市场空间、生态运作等
│   └── 05-团队介绍/            # 核心成员履历、团队核心资质和优势等
├── 02-相关证明材料/
│   ├── 01-参赛团队基本资质（学生身份证明等）/
│   ├── 02-参赛项目基本资质证明/
│   └── 03-应用推广证明/
├── 03-项目介绍PPT/
├── 04-项目介绍视频/
└── 05-其他/
    ├── 01-安装程序及说明文档/
    ├── 02-方案链接及说明文档/
    └── 03-Demo及说明文档/
```

## 材料说明

1. **项目白皮书**：按五个章节分别存放项目概述、解决方案、应用成效、商业模式、团队介绍相关文档。
2. **相关证明材料**：与参赛团队相关的基本资质（如学生身份证明资料），以及与参赛项目相关的基本资质证明、应用推广证明等。所有材料须为参赛队伍所有，严禁使用非参赛队伍材料，否则将取消参赛资格和成绩。
3. **项目介绍 PPT**：存放项目介绍演示文稿。
4. **项目介绍视频**：存放展示产品/解决方案主要内容、效果的视频，帮助评审专家直观了解参赛项目。
5. **其他**：存放可使用的安装程序和说明文档、可使用的方案链接和说明文档、Demo 和说明文档等。

> 各子目录中的 `.gitkeep` 为占位文件，用于保持目录结构，上传实际材料后可自行删除。
