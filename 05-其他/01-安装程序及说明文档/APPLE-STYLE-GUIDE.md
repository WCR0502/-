# MedEcho Apple 风格重设计 - 优化说明

## 🎨 设计理念

参考 Apple 官网的设计语言，为 MedEcho 医疗助手打造更简约、更美观、更流畅的用户界面。

### 核心设计原则

1. **极简主义** - 大量留白，让内容呼吸
2. **柔和美学** - 浅色背景、精致阴影、流畅动画
3. **层次分明** - 清晰的视觉层次和信息架构
4. **流畅交互** - 丝滑的页面切换和微交互
5. **无障碍优先** - 尊重用户的动画偏好设置

---

## ✨ 主要改进

### 1. 视觉设计升级

#### 配色方案
- **主色调**：从医疗绿转为现代青绿色系（#30d158）
- **背景色**：采用 Apple 标准灰白（#f5f5f7）
- **文字颜色**：更深邃的墨色系统（#1d1d1f）
- **语义色**：保留红/黄/蓝但更柔和

#### 排版系统
- 字体：使用 Apple 系统字体栈（SF Pro Display/Text）
- 字号：增大基础字号至 17px，提升可读性
- 行高：优化至 1.6-1.7，更舒适的阅读体验
- 字间距：精细调整（-0.011em），更专业

#### 圆角与阴影
- 大圆角设计（8px-28px 圆角系统）
- 多层柔和阴影，营造层次感
- 悬浮时阴影加深，提供视觉反馈

#### 毛玻璃效果
- 顶栏导航：backdrop-filter 模糊效果
- 应用外壳：半透明背景 + 模糊
- 进度卡片：玻璃态设计

---

### 2. 页面切换动画（核心优化）

#### 退出动画
```
当前页面 → 淡出 + 上移 + 缩小（0.4s）
```

#### 进入动画
```
目标页面 → 淡入 + 下移 + 放大（0.6s）
```

#### 子元素交错动画
- 卡片、标题等元素依次进入
- 延迟 80ms 递增
- 使用 fade-up 动画

#### 导航状态同步
- 实时更新步骤指示器
- 平滑的下划线过渡

---

### 3. 微交互增强

#### 按钮波纹效果
- 点击时产生 Material Design 风格的波纹
- 从点击位置扩散
- 600ms 后自动消失

#### 卡片悬浮光效
- 鼠标悬浮时显示柔和的光晕
- 径向渐变从中心向外扩散
- 提升交互反馈

#### 数字滚动动画
- 统计数字从 0 滚动到目标值
- 使用 easeOutExpo 缓动曲线
- 1秒内完成动画

#### 焦点状态增强
- 3px 绿色轮廓
- 2px 偏移
- 平滑过渡

---

### 4. 滚动显示系统

使用 IntersectionObserver 实现：
- 元素进入视口 15% 时触发动画
- 自动解除观察，避免重复触发
- 支持 staggered 延迟

适用元素：
- 功能卡片（.doc-card）
- 信息卡片（.card, .point-card）
- 章节标题（.sec-head）
- 表单区域（.form-card）

---

### 5. 加载状态管理

全局加载遮罩：
- 半透明白色背景
- 8px 模糊效果
- 旋转加载动画
- 可自定义提示文字

API：
```javascript
// 显示加载
window.MedEchoEnhancements.showLoading('正在整理...');

// 隐藏加载
window.MedEchoEnhancements.hideLoading();

// 包装异步操作
const result = await window.MedEchoEnhancements.withLoading(
  async () => { /* 异步操作 */ },
  '处理中...'
);
```

### 6. 其他细节优化

#### Hero 区域
- 全屏沉浸式设计（420px 高度）

- 渐变色填充
- 0.5s 平滑过渡

#### 弹窗
- iOS 风格圆角（24px）
- 弹簧缓动进入动画
- 毛玻璃背景遮罩

## ♿ 无障碍支持

### 减少动画模式
检测 `prefers-reduced-motion: reduce`：
- 禁用所有动画
- 禁用滚动显示
- 禁用微交互效果
- 保持功能完整性

### 键盘导航
- 清晰的焦点指示器
- 合理的 Tab 顺序
- 语义化 HTML 结构

### 屏幕阅读器
- ARIA 标签支持
- 逻辑的内容顺序
- 有意义的文本替代

## 🔧 切换回原样式

如需恢复原始医疗主题：

1. 打开 `index.html`
2. 注释掉 Apple 风格 CSS：
   ```html
   <!-- <link rel="stylesheet" href="assets/css/apple-style.css" /> -->
   ```
3. 取消注释原样式：
   ```html
   <link rel="stylesheet" href="assets/css/console.css?v=76" />
   ```
4. （可选）注释掉增强脚本：
   ```html
   <!-- <script src="assets/js/apple-enhance.js"></script> -->
   ```

## 💡 使用建议

### 最佳实践
1. **保持简洁**：不要过度添加动画
2. **性能优先**：移动端注意动画数量
3. **用户控制**：尊重减少动画偏好
4. **测试多设备**：确保各端体验一致

### 自定义调整
修改 `apple-style.css` 中的 CSS 变量：
```css
:root {
  --jade: #30d158;        /* 主色调 */
  --r-xl: 24px;           /* 圆角大小 */
  --sh-2: ...;            /* 阴影强度 */
}
```
