# ⚠️ 先读我（重要）

这一版加了后端（会话、档案、分享、安全规则），启动方式没变：**双击 `启动.bat`** 就能用。

但请先看清三件事：

**1. 模型 Key 现在只放在 `.env` 里，不再放 `llm.config.json`**
包里原来那份 Key 已经被上游判为无效（返回 401），所以你现在打开会看到右上角显示「**规则版**」——追问和结论用内置规则生成，**整条流程照样能走完、能演示**。
想恢复 AI：打开根目录的 `.env`，把 `LLM_API_KEY` 换成你自己的 Key，重启黑窗口即可。

**2. `.env` 是本机文件，不会被页面访问到**
以前 `llm.config.json` 放在项目根目录，浏览器可以试着直接请求它；现在静态服务只开放 `public/` 目录，`.env`、数据库、源码都无法通过网址拿到。
即便如此，也**不要把 `.env` 上传到公开仓库、网盘或群里**。

**3. 这是别人（分享者）的账号额度，演示结束后会作废**
不要把它接到你自己的项目里长期使用。你需要长期用，就去申请一个自己的（DeepSeek、通义、智谱都行）。

## 怎么打开

1. 解压到任意文件夹（不要在压缩包里直接双击）
2. 第一次使用先装依赖：在该文件夹打开终端，执行 `npm install`
3. 双击 **`启动.bat`**，等黑窗口出现 `→ http://localhost:5173`
4. 浏览器会自动打开；没打开就把那行地址复制到浏览器

> 黑窗口不要关，关了页面就打不开了。
> 数据库在第一次启动时自动创建（`data/medecho.db`），不用手动建表。

## 怎么确认 AI 通了

打开页面后看**右上角**：

- 显示「**AI 已就绪**」→ Key 可用，追问由模型生成
- 显示「**规则版**」→ Key 没配或已失效，页面会退回内置规则
- 显示「**AI 超时已降级**」→ 这一轮模型没返回，已自动用规则接着问

## 这一版多了什么

- **档案会存下来**：刷新页面、关掉再打开，还在同一份记录上（存在本机数据库里）。
- **分享是真链接**：点「发给家属」会生成一条带随机 token 的链接，24 小时内有效、可随时撤销；链接里没有姓名和症状。
- **知情同意**：第一次进入要先勾选，说明数据会发给模型服务和高德、不是诊断、急症拨 120。
- **基本信息**：年龄区间 / 性别 / 是否怀孕 / 是否吃抗凝药，用于判断急诊优先级（65 岁以上不会给「先在家观察」）。
- **不再显示「疾病概率」**：改成「可能涉及的系统与就诊方向」+「需要医生优先排除的急症」；也不再出现具体药名和剂量。
