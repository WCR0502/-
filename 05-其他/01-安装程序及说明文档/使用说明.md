# 同频 MedEcho · 使用说明（演示版）

> 本包已配置好模型，双击 `启动.bat` 即可使用 AI 追问。Key 的使用边界见 `先读我.md`。

---

## 一、怎么打开（三步）

1. **装 Node.js**（18 或更高版本，[nodejs.org](https://nodejs.org) 下 LTS 包一路下一步）。已装过就跳过。
2. **解压**到任意位置（例如桌面），不要在压缩包里直接双击。
3. 双击 **`启动.bat`**，几秒后浏览器自动打开 `http://localhost:5173`。

> 黑窗口不要关，它就是服务本身。
> 浏览器没自动弹出的话，把窗口里那行 `http://localhost:xxxx` 复制到地址栏。

打不开时先确认：是不是双击成了 `index.html`。直接双击 `index.html` 是离线预览，**没有地图、没有 AI**。

## 二、模型状态

页面右上角会显示当前状态：

| 显示 | 含义 |
|---|---|
| **AI 已就绪** | Key 有效，追问与结论由模型生成（当前 deepseek-chat，每次约 1–2 秒） |
| **规则版** | 没配 Key 或调用失败（断网/限流/超时），已自动降级，流程不受影响 |
| **AI 超时已降级** | 这一轮模型没返回，已用内置规则接着问 |

换模型：改项目根目录 `.env` 里的 `LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY`，**保存后重启服务**（`node server.js`）。

任何 OpenAI 兼容服务都能用：

```
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
LLM_API_KEY=sk-...
```

> 包里最初那份旧 Key 已作废（上游 401）。当前 `.env` 已换成可用的 DeepSeek Key，页面应显示「AI 已就绪」；若显示「规则版」，先重启服务再刷新页面。
> Key 只在服务端读取，浏览器拿不到。

## 三、地图

已内置高德 Web 端 JS API Key，不需要另外配置。

- 点「定位并查找附近医院」→ 浏览器询问位置时选**允许**，否则查不到医院
- 必须在 `http://localhost` 下打开，`file://` 模式下高德 SDK 不工作
- 若提示 `INVALID_USER_DOMAIN`，说明该 Key 在控制台设了域名白名单，需把 `localhost` 加进去

## 四、哪些是真的、哪些是演示数据

| 内容 | 来源 |
|---|---|
| 医院名称、地址、经纬度、距离 | **真实**，高德 POI 实时搜索 |
| 医生姓名、职称、号源余量、就诊时段、挂号费 | **演示数据**，按医院+科室程序生成 |
| 就诊档案里的医嘱、复诊时间、用药 | **演示数据**，不构成处方 |
| 分诊方向与紧急程度 | 模型或规则的**参考意见**，不能替代医生诊断 |

预约按钮只到「核对信息」，不会真的向医院提交挂号。

### 界面说明（当前版本）

整体是「一个大圆角白卡片 + 顶栏 + 五屏内容」的单页结构，每屏顶部都有一条浅绿渐变横幅。

- **顶栏**：左边是十字标 + 品牌名，中间是四个位置标签（首页 / 症状梳理 / 就医指南 / 健康档案），
  右边是模型状态胶囊与「林」头像。标签只表示走到第几步，**不可点击**；
  前进后退请用页面里的按钮。原先的搜索框与「演示账户」入口已彻底移除。
- **横幅（Banner）**：首页是大横幅（标题 + 主按钮 + 医生/患者插画）；
  02–05 是小横幅（面包屑 + 标题 + 右侧进度/定位卡）。
- **导航为什么只有 4 个标签**：稿子把「症状梳理」画成一页，程序里这页拆成「补充细节」和「就医建议」两屏，
  两个屏共用同一个标签，所以你看到的高亮会在两屏之间保持不变。
- **进度数字**：横幅上的百分比与「第 N 个问题」都由服务端 Case File 的真实字段算出来，
  不再使用写死的 86% / 80%；追问轮次、已确认事实条数都能对得上。
- **头像「林」**：演示占位，没有登录体系，点了没反应。
- **装饰曲线**：首页「近 7 天记录示意」、摘要卡里的感受曲线、医院页统计卡底的折线，
  都是写死的 SVG 装饰，**不调用任何接口**，也不参与业务逻辑。

### 就医工具（v2.0.0 新增）

结果页底部新增一张「就医工具」卡片，点开是弹层，不新增导航：

| 工具 | 用途 | 数据来源 |
|---|---|---|
| 就医准备包 | 8–12 项出门清单，可勾选、可打印 | `care_kits`（勾选刷新不丢） |
| 沟通卡 | 全屏大字，医生版 / 家属版，离线可看 | Case File 事实 |
| 急诊卡 | 过敏、用药、基础病、联系人、最后正常时间 | Case File 事实，不含诊断 |
| 家属协同 | 24 小时只读 / 可提问链接，可撤销 | `care_circle_members` |
| 诊后回授 | 输入医生原话 → 3–5 道点选题 → 指出不一致 | `teachback_sessions` |

关闭对应 feature flag（`FEATURE_CAREKIT=0` 等）后，这些入口会返回「功能未开启」，主流程不受影响。

逐屏的「稿子元素 → 代码位置」对照见 `设计稿对照.md`。

## 六、常见问题

**Q：提示端口被占用？**
不会失败，程序会自动往后找空端口，控制台会打印实际地址。

**Q：双击 `启动.bat` 弹出的是记事本或别的程序？**
这台机器的 `.bat` 默认打开方式被改过。右键 → 打开方式 → 选「Windows 命令处理程序」→ 勾选「始终使用」。

**Q：想打印纸质卡？**
在「健康档案」页点「打印就诊卡片」，会输出一张 **A4 纵版单页卡**（就诊信息、进度、症状与咨询计划、就诊准备、健康摘要都在这一页）。打印对话框里纸张选 A4，缩放选「默认 / 100%」，并勾选「背景图形」以保留卡片的米色底和绿色标识。
症状与咨询描述会自动折行，超过两行按纸张版心截断（完整内容仍在页面上的健康档案里）；因此不论描述多长，纸上始终是一页。
想先在屏幕上看这张纸长什么样：在地址后加 `?card=1`（`index.html?card=1`）。
